## Exact default serialization amendment

The coordinator observed an authentic checkpoint round-trip failure caused by inherited `GetOrAddReal` default serialization: a resolved `FLT_MIN` value was stored as `1.17549e-38`, then reparsed to a different binary double. The patch calls existing `SetRealPrecise` for all resolved native EOS floors and immutable seed timing/geometry values before checkpoint input serialization. `SetRealPrecise` uses `numeric_limits<Real>::max_digits10` (`src/parameter_input.cpp:732–741`); the exact contract comparison is retained. This closes the identified serialization mechanism without weakening compatibility checks or changing the resolved values in memory. Independent decimal arithmetic for the floor and nontrivial derived/default values is retained in `default-roundtrip-arithmetic.json`; it is not a native ParameterInput API or full restart test. Enabled-scope finite seed geometry/timing checks reject nonfinite resolved defaults. The follow-up active target threshold check (`src/particles/particles.cpp:257–266`) also rejects NaN/infinite target minima or maxima before serialization; otherwise NaN comparison semantics could silently bypass the requested filter. This follow-up finding is source-closed. Native replay of the final corrected binary remains an independent acceptance gate.

## Timing, numerical reuse and state identity

- Initial observations occur after conserved/primitive ghost refresh and initial MC seeding (`src/driver/driver.cpp:345–356`). Native MC particles are cell-parent tracers. They do not follow a deterministic velocity-integrated continuous path.
- Completed-step observations occur after all fluid stages and `after_timeintegrator` MC push, parent reassignment, compaction/migration, receipt and scheduled seeding, at `t_n+dt` and generation `ncycle+1`, before the mesh counters advance (`src/driver/driver.cpp:466–483`; task ordering in `src/particles/particles_tasks.cpp`). The diagnostic generation guard prevents repeated sampling of an already sampled checkpoint (`src/particles/shock_particles.cpp:236–239`).
- Append initializes only newborn encounter state (`src/particles/shock_particles.cpp:167–175`) and retains pre-existing state through resize. Newborn first observation uses the actual completed fluid generation. Native creation-time fields retain requested seed schedule times; catch-up births may have earlier requested creation times and do not acquire invented prior transfers.
- Both frozen native headers are byte-identical to the previous numerical/state packet. Primitive field ordering remains rho, three velocities, internal-energy density; ideal pressure is `(gamma-1)*IEN`. Physical x/y/z spacing maps to native i/j/k. Unreduced nearest-axis temperature-normal membership, pressure-gradient finite checks and comparator semantics were not changed. The earlier parity packet is reference evidence; qualification on this branch/binary must be recorded separately.
- MC checks reject nonfinite/invalid parent mass, nonfinite touched face fluxes or outgoing probability sum above one before valid transfers are consumed (`src/particles/particles_lagrangian_mc.cpp:564–584`). This prevents the inherited cumulative-selection truncation from silently biasing an overfull probability set in the enabled scope.
- Optional transfer evidence records 17 fields before migration, with source parent, actual draw/probabilities/direction and completed-step time bin (`src/particles/shock_particles.cpp:215–233`). Post-transfer observations record destination parents. Transfer records are diagnostic evidence of a discrete stochastic operation, not continuous trajectories or exact crossing times.

## Paired persistence and history prefix

The native `ATHKPRTCLMC` v1 section persists all seven real rows, five integer rows, seed schedule progress and next tag. The `AKSHOCK2` v2 sidecar separately persists full `EncounterState`; it is not a replacement for native MC state. Configuration binds the implementation fingerprint, detector settings, EOS/solver/integrator/reconstruction/CFL, mesh/block geometry and boundaries, MC RNG seed and static seed schedule definitions (`src/particles/particles.cpp` (full contract construction)). Dynamic schedule progress is restored from native metadata, with unique schedule IDs enforced.

The sidecar reader checks ABI/endianness/Real/int/state sizes, rank count/partition, array layout/count, fluid time/generation, exact contract and lineage, exact file length/checksum and paired native payload digest. Every restored native tag must match its encounter ID, IDs must be unique locally, phase must be valid, generation must match the checkpoint and positions must lie in the declared owned blocks (`src/particles/shock_particles.cpp:479–548`). Event-prefix manifest and every committed generation chunk, including empty generations, must exist and match the stored chained digest (`src/particles/shock_particles.cpp:179–205`). Replayed future chunks are accepted only if identical; the implementation does not silently start a replacement history stream. Domain-exit events are queued before destructive compaction and bounded output overflow fails loudly. State migration is whole-record; actual MPI routing is independently owned and tested by the migration/test packet, not claimed by this source review.

The raw sidecar ABI and source/partition contract intentionally restrict restart compatibility. There is no claim of cross-platform, changed-rank, per-node, AMR or different-physics portability. FNV integrity checks target accidental corruption, as the source states.
